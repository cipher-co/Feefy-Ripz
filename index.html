Pokémon Card Pack Trick Guide

"Card Trick" คือเทคนิคการสับย้ายการ์ดจากด้านหลังซองมาไว้ด้านหน้า เพื่อซ่อนการ์ดหายาก (Rare / Secret Rare / Holo) ไว้เปิดลุ้นเป็นใบสุดท้ายเพื่อความตื่นเต้น!

ยุค (Series) ช่วงปีที่ออก จำนวนการ์ดที่ต้องสับ ตัวอย่าง Set

ถอด Code Card ก่อนเสมอ

เปิดซองแล้วหันหลังซองเข้าหาตัว ดึง Code Card ด้านหลังออกก่อนทุกครั้ง เพราะสี Code Card ในยุคเก่าอาจบอกระดับความหายากล่วงหน้าได้

ยุค Scarlet & Violet (1 ใบ)
